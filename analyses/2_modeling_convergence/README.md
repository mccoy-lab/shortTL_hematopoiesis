## Modeling the probability of repeated evolution in HSC population

This directory contains an R markdown that details the code and models used to estimate the probability of repeated (parallel) evolution of a single-nucleotide polymorphism within a population of HSCs with aging (assuming a fixed population size and genome-wide mutation rate).
