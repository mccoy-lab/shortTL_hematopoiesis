# Stochastic character mapping

This directory contains knitted renderings of `Rmarkdown` notebooks that describe the application of stochastic character mapping to somatic mutation histories. 

Renders of the markdown can be found below:
- [PDF knit](scm.pdf)
- [HTML knit](scm.html)

An `anaconda` environment recipe is provided in [env.yaml](env.yaml), and [scm_functions.R](scm_functions.R) contains bespoke functions to import data and perform stochastic character mapping.
